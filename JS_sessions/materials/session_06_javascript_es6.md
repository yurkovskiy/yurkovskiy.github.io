# Модуль 1: Регулярні вирази в JavaScript

## 1.1 Основна концепція та синтаксис створення

**Регулярний вираз** (Regular Expression / RegExp) — це формальна мова для пошуку, синтаксичного аналізу та маніпуляцій з підрядками в тексті. У JavaScript регулярні вирази є об'єктами першого класу (first-class objects) і представлені вбудованим класом `RegExp`.

### Варіанти синтаксису створення

1. **Літерал регулярного виразу:** компілюється під час завантаження скрипту; ідеально підходить, коли шаблон залишається незмінним (статичним).
   ```javascript
   const literalRegex = /pattern/flags;
   ```

2. **Конструктор `RegExp`:** компілюється під час виконання програми (runtime); необхідний, коли шаблон генерується динамічно зі змінних або зовнішніх даних.
   ```javascript
   const dynamicPattern = "user_input";
   const constructorRegex = new RegExp(dynamicPattern, "gi");
   ```

## 1.2 Прапорці (Flags) регулярних виразів

Прапорці змінюють режим зіставлення шаблону з цільовим рядком:

| Прапорець | Значення | Опис |
| :--- | :--- | :--- |
| `g` | Глобальний пошук (Global) | Знаходить усі збіги замість зупинки після першого знайденого. |
| `i` | Нечутливість до регістру (Case-insensitive) | Не розрізняє великі та малі літери (`x` та `X` еквівалентні). |
| `m` | Багаторядковий режим (Multiline) | Символи `^` та `$` позначають початок і кінець кожного рядка (`\n`), а не лише всього тексту. |
| `s` | Режим "dotAll" | Дозволяє крапці `.` збігатися також із символами переходу на новий рядок (`\n`, `\r`). |
| `u` | Повна підтримка Unicode | Забезпечує коректну роботу з сурогатними парами та 32-бітними символами Unicode. |
| `y` | "Липкий" режим (Sticky) | Шукає збіг суворо за поточною позицією `lastIndex`, не пропускаючи символи вперед. |

## 1.3 Методи RegExp (`exec`, `test`)

### `RegExp.prototype.test(str)`
Перевіряє наявність збігу в рядку. Повертає булеве значення (`true` або `false`).

```javascript
const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
console.log(emailPattern.test("dev@example.com")); // true
console.log(emailPattern.test("invalid-email"));    // false
```

### `RegExp.prototype.exec(str)`
Виконує пошук збігу в рядку. Повертає масив із результатами (повний збіг, групи захоплення, індекс і початковий рядок) або `null`, якщо збіг відсутній.

```javascript
const pattern = /item-(\d+)/;
const match = pattern.exec("Processed item-42 in queue");

if (match) {
  console.log(match[0]);     // "item-42" (повний збіг)
  console.log(match[1]);     // "42" (знайдена підгрупа)
  console.log(match.index); // 10 (позиція початку збігу)
}
```

> **Важливий нюанс щодо `lastIndex`:** За наявності прапорця `g` методи `exec()` та `test()` зберігають стан і оновлюють властивість `regexp.lastIndex` після кожного виклику. Скидайте її вручну (`regexp.lastIndex = 0`), якщо повторно використовуєте один екземпляр регулярного виразу для різних рядків.

## 1.4 Методи рядків для роботи з RegExp

```javascript
const text = "apple, orange, banana, apple";

// 1. search(): Повертає індекс першого збігу або -1
console.log(text.search(/orange/)); // 7

// 2. split(): Розбиває рядок на масив за заданим патерном
const csvLine = "Name; Age;  Location;Status";
console.log(csvLine.split(/\s*;\s*/)); 
// ["Name", "Age", "Location", "Status"]

// 3. match(): Повертає масив збігів (усі збіги за наявності прапорця 'g') або null
console.log(text.match(/apple/g)); // ["apple", "apple"]

// 4. replace(): Замінює збіги шаблону
// Без прапорця 'g' замінюється тільки перший збіг!
const updated = text.replace(/apple/g, "peach");
console.log(updated); // "peach, orange, banana, peach"
```

## 1.5 Набори, діапазони та метасимволи

### Набори та діапазони
* `[xyz]`: Будь-який один символ із зазначених (`x`, `y` або `z`).
* `[a-z]`: Діапазон літер у нижньому регістрі.
* `[0-9]`: Цифровий діапазон від 0 до 9.
* `[^0-9]`: Виключаючий діапазон (будь-який символ, крім цифр).
* `[a-zA-Z0-9_-]`: Комбінований набір літер, цифр, дефіса та підкреслення.

### Основні метасимволи
* `\d`: Будь-яка десяткова цифра, еквівалентно `[0-9]`.
* `\D`: Будь-який символ, що не є цифрою, еквівалентно `[^0-9]`.
* `\w`: Будь-який алфавітно-цифровий символ або підкреслення, еквівалентно `[A-Za-z0-9_]`.
* `\W`: Будь-який символ, крім алфавітно-цифрових та підкреслення, еквівалентно `[^A-Za-z0-9_]`.
* `\s`: Будь-який пробільний символ (пробіл, табуляція `\t`, новий рядок `\n`).
* `\S`: Будь-який непробільний символ.
* `\0`: Нульовий символ (null).
* `\n`: Символ переходу на новий рядок.
* `.`: Будь-який символ, крім символу нового рядка (якщо не активовано прапорець `s`).

## 1.6 Квантифікатори, якорі та логічне «АБО»

### Квантифікатори (Кількість повторень)
* `*`: 0 або більше повторень попереднього символу (еквівалентно `{0,}`).
* `+`: 1 або більше повторень (еквівалентно `{1,}`).
* `?`: 0 або 1 повторення (робить елемент необов'язковим; `{0,1}`).
* `{n}`: Рівно $n$ повторень.
* `{n,}`: Від $n$ і більше повторень.
* `{n,m}`: Від $n$ до $m$ повторень включно.

### Якорі та групування
* `^`: Початок рядка (або тексту).
* `$`: Кінець рядка (або тексту).
* `(...)`: Група захоплення (Capturing group). Квантифікатори застосовуються до всієї групи разом.
* `|`: Логічне «АБО» (абонемент/чергування).
* `\`: Екранування спеціальних символів (`.`, `*`, `+`, `?`, `^`, `$`, `(`, `)`, `[`, `]`, `\`, `/`).

```javascript
// Перевірка формату UUID v4
const uuidRegex = /^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i;
console.log(uuidRegex.test("c9a646d3-9c61-4cc9-bc18-2e06f9d3b1e3")); // true
```

## 1.7 Валідація HTML5-форм за допомогою RegExp

Браузери підтримують нативну клієнтську валідацію полів введення за допомогою атрибута `pattern`:

```html
<form>
  <!-- Вимагає: 3 великі літери, дефіс, 4 цифри -->
  <label for="sku">Артикул товару (SKU):</label>

    type="text" 
    id="sku" 
    name="sku" 
    pattern="[A-Z]{3}-\d{4}"

    required
  />
  <button type="submit">Надіслати</button>
</form>
```

# Модуль 2: Сучасний JavaScript (ECMAScript 2015+)

## 2.1 Еволюція стандарту, `let`/`const` та Babel

### Babel.js
Babel — це транспілятор (компілятор з вихідного коду у вихідний код), який перетворює сучасний код стандарту ES6+ на сумісний код попереднього стандарту ES5 для коректного виконання у старіших браузерах та середовищах.

### `var` у порівнянні з `let` та `const`

| Характеристика | `var` | `let` | `const` |
| :--- | :--- | :--- | :--- |
| **Область видимості** | Функціональна / Глобальна | Блокова (`{ ... }`) | Блокова (`{ ... }`) |
| **Підняття (Hoisting)** | Ініціалізується як `undefined` | Піднімається у TDZ (Temporal Dead Zone) | Піднімається у TDZ |
| **Повторне оголошення** | Дозволено в тій самій області | Помилка (`SyntaxError`) | Помилка (`SyntaxError`) |
| **Переприсвоєння** | Дозволено | Дозволено | Заборонено (`TypeError`) |

#### Блокова область видимості у циклах

```javascript
// var створює єдину спільну змінну для всіх ітерацій
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(`var: ${i}`), 10);
}
// Виведе: "var: 3", "var: 3", "var: 3"

// let створює нову змінну для кожної окремої ітерації
for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(`let: ${j}`), 10);
}
// Виведе: "let: 0", "let: 1", "let: 2"
```

## 2.2 Шаблонні рядки та стрілкові функції

### Шаблонні рядки (Template Literals)
Оголошуються у зворотних лапках (`` ` ``). Підтримують перенесення рядків без спецсимволів та інтерполяцію виразів через синтаксис `${вираз}`:

```javascript
const user = { name: "Олександр", role: "Адміністратор", activeSessions: 3 };
const summary = `Користувач: ${user.name}
Роль: ${user.role}
Активний статус: ${user.activeSessions > 0 ? "Так" : "Ні"}`;
```

### Стрілкові функції (Arrow Functions)
Стрілкові функції мають короткий синтаксис і, що найважливіше, **не мають власного контексту `this`** — вони лексично прив'язують значення `this` з навколишньої функції:

```javascript
function Timer() {
  this.seconds = 0;

  // Стрілкова функція успадковує 'this' від екземпляра Timer
  setInterval(() => {
    this.seconds++;
  }, 1000);
}

const timer = new Timer();
```

*Примітка: Стрілкові функції не мають власного `this`, об'єкта `arguments`, `super`, `new.target` і не можуть використовуватись як функції-конструктори (`new`).*

## 2.3 Оператор Spread (`...`) та параметри Rest

### Параметри Rest (залишкові параметри)
Збирають невизначену кількість аргументів функції в повноцінний масив:

```javascript
function logReport(category, ...records) {
  console.log(`Категорія: ${category}`);
  console.log(`Кількість записів: ${records.length}`);
  records.forEach(r => console.log(`- ${r}`));
}

logReport("База даних", "З'єднання встановлено", "Міграція успішна", "Синхронізація завершена");
```

### Оператор Spread (поширення / розгортання)
Розгортає елементи масиву чи ітерованого об'єкта у список аргументів функції, новий масив або властивості об'єкта:

```javascript
// Передача елементів масиву в аргументи функції
const numbers = [45, 12, 89, 3];
console.log(Math.max(...numbers)); // 89

// Поверхневе копіювання та об'єднання масивів
const base = [1, 2];
const merged = [0, ...base, 3, 4]; // [0, 1, 2, 3, 4]

// Поверхневе об'єднання об'єктів
const configDefaults = { port: 3000, debug: false };
const envOverrides = { debug: true, host: "0.0.0.0" };
const serverConfig = { ...configDefaults, ...envOverrides };
```

## 2.4 Деструктуризація (Destructuring Assignment)

Синтаксична конструкція, що дозволяє «розпаковувати» значення з масивів або властивості з об'єктів безпосередньо в окремі змінні.

### Деструктуризація масивів

```javascript
const coords = [19.04, 47.49, 102];
const [lng, lat] = coords;          // 19.04, 47.49
const [, , alt] = coords;           // Пропуск перших двох елементів -> 102
const [x, ...remaining] = coords;   // remaining = [47.49, 102]
```

### Деструктуризація об'єктів та параметрів

```javascript
const profile = {
  id: "usr_99",
  credentials: { username: "octocat" },
  active: true
};

// Перейменування (aliasing) та вкладена деструктуризація
const { 
  id: userId, 
  credentials: { username }, 
  theme = "dark" // значення за замовчуванням
} = profile;

console.log(userId, username, theme); // "usr_99", "octocat", "dark"

// Деструктуризація безпосередньо в списку параметрів функції
function renderCard({ title, width = 300 }) {
  return `Картка "${title}" шириною ${width}px`;
}
```

## 2.5 Символи (Symbol) та протокол ітерації

### Символи (Symbol)
Новий примітивний тип даних, що створює повністю унікальні ідентифікатори.

```javascript
const id1 = Symbol("id");
const id2 = Symbol("id");
console.log(id1 === id2); // false

// Глобальний реєстр символів
const sharedKey1 = Symbol.for("app.auth");
const sharedKey2 = Symbol.for("app.auth");
console.log(sharedKey1 === sharedKey2); // true
console.log(Symbol.keyFor(sharedKey1)); // "app.auth"
```

#### «Приховані» властивості об'єктів
Властивості, де ключем є символ, ігноруються циклами `for..in` та методом `Object.keys()`:

```javascript
const internalId = Symbol("internalId");
const entity = {
  name: "ServiceInstance",
  [internalId]: "A71-994"
};

console.log(Object.keys(entity)); // ["name"]
console.log(entity[internalId]);   // "A71-994"
```

### Ітератори та `Symbol.iterator`
Будь-який об'єкт, що реалізує метод `[Symbol.iterator]`, є ітерованим (iterable) і може перебиратися циклом `for..of`.

```javascript
const customRange = {
  start: 1,
  end: 3,
  [Symbol.iterator]() {
    let current = this.start;
    const last = this.end;
    return {
      next() {
        if (current <= last) {
          return { value: current++, done: false };
        }
        return { value: undefined, done: true };
      }
    };
  }
};

for (const val of customRange) {
  console.log(val); // 1, 2, 3
}
```

## 2.6 Колекції: `Set` та `Map`

### Колекція `Set`
Структура даних, що зберігає виключно унікальні значення будь-якого типу.

```javascript
const tagSet = new Set(["js", "ts", "node", "js"]);

tagSet.add("react");
console.log(tagSet.size);         // 4
console.log(tagSet.has("node"));   // true

tagSet.delete("ts");
tagSet.forEach(tag => console.log(tag));

// Швидка дедуплікація масиву
const duplicates = [1, 2, 2, 3, 4, 4, 1];
const uniqueList = [...new Set(duplicates)]; // [1, 2, 3, 4]
```

### Колекція `Map`
Словникова структура даних у форматі пар `[ключ, значення]`. На відміну від звичайних об'єктів, ключем у `Map` може бути **абсолютно будь-який тип даних** (включно з об'єктами, функціями та примітивами).

```javascript
const registry = new Map();

const keyObj = { namespace: "core" };
registry.set(keyObj, { status: "operational" });
registry.set("timeout", 5000);

console.log(registry.get(keyObj));   // { status: "operational" }
console.log(registry.has("timeout")); // true
console.log(registry.size);          // 2

// Ітерація по колекції Map
for (const [key, val] of registry.entries()) {
  console.log(key, "=>", val);
}
```

## 2.7 Швидка шпаргалка (Summary Table)

| Концепція | Основний синтаксис / API | Ключова перевага / Правило |
| :--- | :--- | :--- |
| **Зіставлення RegExp** | `re.test(s)` / `re.exec(s)` | Швидка валідація рядків та витяг токенів. |
| **Трансформація рядків** | `s.replace(re, fn)` / `s.split(re)` | Гнучка нормалізація тексту та парсинг. |
| **Змінні блокової видимості** | `let`, `const` | Усувають баги підняття змінних (hoisting), блоковий скоуп. |
| **Стрілкові функції** | `() => expr` | Зберігають лексичний контекст `this`. |
| **Spread / Rest** | `...iterable`, `...obj` | Зручне копіювання/злиття без мутацій та гнучкі списки аргументів. |
| **Деструктуризація** | `const { a, b } = obj` | Компактний розбір структур даних із дефолтними значеннями. |
| **Символи (Symbol)** | `Symbol("label")` | Унікальні ідентифікатори, захист ключів від колізій. |
| **Ітератори** | `[Symbol.iterator]()` | Уніфікований протокол перебору даних для циклу `for..of`. |
| **Set та Map** | `new Set()`, `new Map()` | Вбудовані структури для множин унікальних значень та довільних ключів. |
