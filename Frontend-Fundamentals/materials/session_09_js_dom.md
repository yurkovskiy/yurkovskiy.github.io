# Конспект: Робота з DOM у JavaScript

Цей конспект охоплює базові та ключові концепції роботи з об'єктною моделлю документа (**DOM**) у JavaScript: від розуміння того, як браузер бачить HTML-сторінку, до пошуку та динамічного створення нових елементів.

---

## Частина 1: DOM у загальному (Призначення, структура, типи вузлів)

### Що таке DOM?
**DOM (Document Object Model — Об'єктна модель документа)** — це програмний інтерфейс (API) для HTML та XML документів. Коли браузер завантажує вебсторінку, він перетворює звичайний текстовий HTML-код на дерево об'єктів у пам'яті. 

**Головне призначення DOM:** надати мовам програмування (насамперед JavaScript) можливість взаємодіяти зі сторінкою — читати та змінювати її структуру, вміст і стилі «на льоту» без перезавантаження.

### Деревоподібна структура (DOM-дерево)
У DOM кожен HTML-тег, текст усередині нього і навіть коментар стають **вузлами (Nodes)**. Вузли пов'язані між собою ієрархічними відносинами (батьківські, дочірні, сусідні).

```text
                       [ document ]
                            │
                        <html>
                       /      \
                 <head>        <body>
                   │          /      \
               <title>      <h1>      <p>
                 │           │         │
           "Мій сайт"   "Привіт!"  "Текст абзацу"
```

### Основні типи вузлів (Node Types)
Хоча в DOM існує 12 типів вузлів, на практиці ми найчастіше стикаємося з чотирма:
1. **Document (Документ)** — кореневий вузол, точка входу в DOM (об'єкт `document`).
2. **Element (Елемент)** — самі HTML-теги (`<div>`, `<p>`, `<a>` тощо). Вони формують структуру сторінки.
3. **Text (Текстовий вузол)** — текст усередині тегів (включно з пробілами та переносами рядків).
4. **Comment (Коментар)** — HTML-коментарі `<!-- ... -->`.

### Навігація по DOM-дереву
Ми можемо переміщатися між вузлами, використовуючи родинні зв'язки. Важливо розрізняти навігацію по **всіх вузлах** (включно з текстом/пробілами) та навігацію **лише по елементах** (тегах):

```text
                  [ parentElement ] (Батьківський тег)
                          ▲
                          │
[ previousElementSibling ] ◄── [ ЕЛЕМЕНТ ] ──► [ nextElementSibling ]
  (Попередній сусід)              │              (Наступний сусід)
                                  ▼
                    [ firstElementChild ] ... [ lastElementChild ]
                              (Дочірні теги)
```

* `parentNode` / `parentElement` — доступ до батьківського вузла / елемента.
* `childNodes` / `children` — колекція всіх дочірніх вузлів / лише дочірніх HTML-елементів.
* `firstChild` / `firstElementChild` — перший дочірній вузол / елемент.
* `lastChild` / `lastElementChild` — останній дочірній вузол / елемент.
* `previousSibling` / `previousElementSibling` — попередній сусідній вузол / елемент.
* `nextSibling` / `nextElementSibling` — наступний сусідній вузол / елемент.

## Частина 2: Отримання DOM-вузлів (Пошук елементів)

Щоб змінити елемент, його спочатку потрібно знайти. У JavaScript є два підходи: класичні методи `getElement(s)By...` та сучасні універсальні методи `querySelector...`.

### 1. Класичні методи пошуку
Ці методи працюють дуже швидко, але мають обмежений функціонал (шукають лише за одним конкретним критерієм).

* **`document.getElementById('id')`**
  Повертає **один** елемент із вказаним атрибутом `id` або `null`, якщо елемент не знайдено.
  ```javascript
  const header = document.getElementById('main-header');
  ```

* **`element.getElementsByClassName('class')`**
  Повертає **живу колекцію** (`HTMLCollection`) усіх елементів із вказаним класом.
  ```javascript
  const buttons = document.getElementsByClassName('btn');
  ```

* **`element.getElementsByTagName('tag')`**
  Повертає **живу колекцію** (`HTMLCollection`) усіх елементів із вказаним тегом.
  ```javascript
  const paragraphs = document.getElementsByTagName('p');
  ```

* **`document.getElementsByName('name')`**
  Повертає колекцію елементів із вказаним атрибутом `name` (зазвичай використовується для полів форм).

### 2. Сучасні універсальні методи (CSS-селектори)
Ці методи дозволяють шукати елементи за будь-яким валідним CSS-селектором (класом, тегом, ID, атрибутом, вкладеністю тощо).

* **`element.querySelector('selector')`**
  Повертає **перший** знайдений елемент, який відповідає CSS-селектору, або `null`.
  ```javascript
  const firstCard = document.querySelector('.container > .card.active');
  ```

* **`element.querySelectorAll('selector')`**
  Повертає **статичну колекцію** (`NodeList`) усіх елементів, що відповідають селектору.
  ```javascript
  const allLinks = document.querySelectorAll('nav a[href^="https"]');
  ```

### Порівняння підходів та типів колекцій

| Характеристика | `getElementsBy...` | `querySelectorAll` |
| :--- | :--- | :--- |
| **Тип повернення** | `HTMLCollection` | `NodeList` |
| **Оновлення (Живість)** | **Жива колекція** (автоматично оновлюється при зміні DOM) | **Статична колекція** (знімок DOM на момент виклику) |
| **Метод `.forEach()`** | Не підтримується напряму (потрібно перетворювати через `Array.from()`) | Підтримується «з коробки» |
| **Гнучкість пошуку** | Тільки один критерій (тег або клас) | Будь-який складний CSS-селектор |

## Частина 3: Створення, налаштування та додавання DOM-вузлів

Динамічне створення контенту зазвичай складається з 3 кроків: **створити** елемент у пам'яті, **налаштувати** його (текст, класи, атрибути) та **вставити** в DOM-дерево.

### Крок 1: Створення елемента
* **`document.createElement('tagName')`** — створює новий порожній HTML-елемент у пам'яті. На сторінці він з'явиться лише після вставки.
* **`document.createTextNode('text')`** — створює текстовий вузол (використовується рідше, оскільки простіше задавати текст через властивості елемента).

```javascript
const newCard = document.createElement('div');
```

### Крок 2: Налаштування вмісту, атрибутів та класів

#### Робота з вмістом:
* `element.textContent = 'Текст'` — безпечно додає або змінює текстовий вміст (HTML-теги всередині сприймаються як звичайний текст).
* `element.innerHTML = '<span>HTML</span>'` — парсить рядок як HTML-розмітку (використовувати обережно через ризик XSS-атак, якщо дані приходять від користувача).

#### Робота з атрибутами:
* `element.setAttribute('name', 'value')` — встановлює або змінює атрибут.
* `element.getAttribute('name')` — отримує значення атрибута.
* `element.hasAttribute('name')` — перевіряє наявність атрибута (`true`/`false`).
* `element.removeAttribute('name')` — видаляє атрибут.

```javascript
newCard.setAttribute('id', 'card-1');
newCard.setAttribute('data-category', 'news');
```

#### Робота з CSS-класами (`classList`):
Властивість `classList` надає зручні методи для керування класами елемента без перезапису всього рядка класів:
* `element.classList.add('class1', 'class2')` — додає один або кілька класів.
* `element.classList.remove('class1')` — видаляє клас.
* `element.classList.toggle('active')` — додає клас, якщо його немає, і видаляє, якщо він є.
* `element.classList.contains('active')` — перевіряє наявність класу (`true`/`false`).

```javascript
newCard.classList.add('card', 'card-shadow');
```

### Крок 3: Вставка елементів у DOM
Сучасні методи вставки дозволяють розмістити створений елемент відносно будь-якого іншого елемента в DOM. Вони приймають як DOM-вузли, так і звичайні текстові рядки (можна передавати кілька аргументів через кому).

```text
                   ┌── parent.before(el)   (Перед самим контейнером)
                   │
[ parent ] ────────┼── parent.prepend(el)  (На початок, всередину контейнера)
  │ ...            │
  │ (існуючий      ├── parent.append(el)   (У кінець, всередину контейнера)
  │  вміст)        │
                   └── parent.after(el)    (Після самого контейнера)
```

* **`node.append(...nodes or strings)`** — вставляє вузли або рядки в **кінець** `node` (як останніх дітей).
* **`node.prepend(...nodes or strings)`** — вставляє вузли або рядки на **початок** `node` (як перших дітей).
* **`node.before(...nodes or strings)`** — вставляє вузли або рядки **безпосередньо перед** `node` (на тому ж рівні вкладеності).
* **`node.after(...nodes or strings)`** — вставляє вузли або рядки **безпосередньо після** `node` (на тому ж рівні вкладеності).
* **`node.replaceWith(...nodes or strings)`** — замінює сам `node` на передані вузли або рядки.
* **`node.remove()`** — видаляє вузол із DOM-дерева.

*(Примітка: старий метод `parent.appendChild(node)` досі зустрічається, але він приймає лише один DOM-вузол, не працює з рядками і повертає вставлений елемент).*

### Повний приклад: від створення до вставки

```javascript
// 1. Знаходимо батьківський контейнер на сторінці
const container = document.querySelector('#cards-container');

// 2. Створюємо новий елемент
const article = document.createElement('article');

// 3. Налаштовуємо класи, атрибути та вміст
article.classList.add('news-item', 'featured');
article.setAttribute('data-id', '101');
article.innerHTML = `
  <h2>Заголовок новини</h2>
  <p>Короткий опис події, створений через JS.</p>
`;

// 4. Додаємо елемент у кінець контейнера
container.append(article);
```
