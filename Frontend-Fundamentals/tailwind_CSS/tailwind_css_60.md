# Tailwind CSS за 60 хвилин — план заняття

**Аудиторія:** студенти, які тільки починають знайомство з підходом Utility-First CSS (базові знання HTML/CSS є, бажано базове розуміння звичайного CSS або досвід роботи з іншими фреймворками на кшталт Bootstrap).  
**Мета:** зрозуміти філософію Utility-First («чому не звичайні класи?»), навчитися створювати адаптивні макети на Grid/Flexbox за підходом Mobile-First, стилізувати інтерактивні стани (`hover:`, `focus:`) та побудувати адаптивну навігаційну панель без виходу з HTML.  
**Формат:** живе кодування / повторення за викладачем. Заздалегідь підготуйте відкритий [Tailwind Play](https://play.tailwindcss.com/) або локальний файл `index.html` із підключеним скриптом Tailwind Play CDN.

## 1. Вступ: яку проблему вирішує Tailwind CSS? (5 хв)

Почніть із запитання: *«Скільки разів ви зупинялися під час верстки лише тому, що не знали, як назвати CSS-клас: `.card-wrapper`, `.card-container`, чи `.card-inner`?»*

Покажіть дві проблеми традиційного підходу:
1. **Перемикання контексту:** постійні стрибки між файлом `index.html` та `style.css`.
2. **Страх ламати старе:** CSS-файли з часом лише розростаються, бо всі бояться видаляти старі класи, які можуть використовуватися десь на іншій сторінці.

Покажіть два приклади створення однакової кнопки:
- Традиційний CSS: клас `.btn-primary` з 8 рядками правил у зовнішньому файлі.
- Tailwind CSS: утилітарні класи прямо в HTML (`bg-blue-600 hover:bg-blue-700 text-white font-medium py-2 px-4 rounded-lg transition`).

**Ключова фраза:** *«Tailwind CSS не нав'язує готові віджети, як Bootstrap. Він дає набір низькорівневих цеглинок-утиліт, із яких ви будуєте власний, абсолютно унікальний дизайн, взагалі не виходячи з HTML-розмітки.»*

## 2. Філософія Tailwind CSS (10 хв)

Представте філософію як чотири основні стовпи:

### а) Utility-First (спочатку утиліти)
Замість семантичних класів компонентів на кшталт `.card` чи `.navbar`, ви використовуєте маленькі класи з однією конкретною функцією (`flex`, `text-center`, `p-4`, `w-full`). Це позбавляє проблеми вигадування назв і гарантує, що розмір вашого фінального CSS-файлу не зростає пропорційно кількості сторінок.

### б) Mobile-First та варіантні префікси
Tailwind використовує інтуїтивну префіксну систему. Базовий клас завжди працює на мобільних пристроях, а префікси на кшталт `sm:`, `md:`, `lg:` застосовують правила лише від зазначеної ширини й вище:
- `w-full md:w-1/2` → на мобільному на всю ширину, від планшета й вище — наполовину.

### в) Псевдокласи та стани прямо в розмітці
Немає потреби писати `:hover`, `:focus`, `:active` чи темну тему в CSS-файлах. Достатньо додати префікс стану перед будь-якою утилітою: `hover:bg-indigo-600`, `focus:ring-2`, `dark:bg-slate-900`.

### г) Дизайн-система за замовчуванням
Вам не потрібно думати, чи задати `margin: 17px` чи `margin: 19px`. У Tailwind закладена збалансована шкала відступів (крок 4px), підібрана палітра кольорів та вивірені розміри шрифтів. Це забезпечує візуальну узгодженість проєкту "з коробки".

**Питання для обговорення (1 хв):** *«Які очевидні мінуси ви бачите в такому підході?»* → Підведіть до відповіді: незвичний, візуально перевантажений HTML-код на початках та необхідність вивчити назви основних утиліт. Проте перевага у швидкості та відсутності "мертвого коду" переважає цей бар'єр.

## 3. Налаштування (5 хв)

Покажіть найшвидший спосіб старту без складних бандлерів (Vite/PostCSS) за допомогою Play CDN.

```html
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Демо Tailwind CSS</title>
  <!-- Tailwind Play CDN (для навчання та прототипування) -->
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-100 text-slate-800 flex items-center justify-center min-h-screen">

  <h1 class="text-3xl font-bold text-indigo-600">
    Привіт, Tailwind CSS!
  </h1>

</body>
</html>
```

**Обов'язково наголосіть на:**
- CDN-скрипт зручний для навчання, швидких прототипів та Tailwind Play, але для реального продакшну використовується збірка через CLI або Vite (яка видаляє всі невикористані стилі та стискає файл до 10–20 КБ).
- Тег `<meta name="viewport">` є критично важливим для роботи точок перелому.

## 4. Розкладка: Flexbox, Grid та адаптивний дизайн (15 хв)

На відміну від 12-колонкової сітки Bootstrap, у Tailwind можна використовувати нативні сучасні CSS Grid та Flexbox із неймовірною легкістю.

Покажіть створення адаптивної сітки з трьох карток:

```html
<div class="max-w-6xl mx-auto p-6">
  <div class="grid grid-cols-1 md:grid-cols-3 gap-6">
    <div class="bg-white p-6 rounded-xl shadow-md border border-slate-200">
      <h3 class="font-bold text-lg text-slate-900 mb-2">Колонка 1</h3>
      <p class="text-slate-600 text-sm">Вміст першої картки нашої адаптивної сітки.</p>
    </div>
    <div class="bg-white p-6 rounded-xl shadow-md border border-slate-200">
      <h3 class="font-bold text-lg text-slate-900 mb-2">Колонка 2</h3>
      <p class="text-slate-600 text-sm">Вміст другої картки нашої адаптивної сітки.</p>
    </div>
    <div class="bg-white p-6 rounded-xl shadow-md border border-slate-200">
      <h3 class="font-bold text-lg text-slate-900 mb-2">Колонка 3</h3>
      <p class="text-slate-600 text-sm">Вміст третьої картки нашої адаптивної сітки.</p>
    </div>
  </div>
</div>
```

Розберіть уголос:
- `grid` → перетворює контейнер на CSS Grid.
- `grid-cols-1` → за замовчуванням (мобільні екрани) розміщує елементи в одну колонку (стек по вертикалі).
- `md:grid-cols-3` → від точки перелому `md` (768px) і ширше — трансформує розкладку в 3 рівні колонки.
- `gap-6` → відстань між елементами (1.5rem / 24px) без від'ємних марджинів.

**Демонстрація наживо:** змінюйте ширину вікна браузера й покажіть, як елементи плавно перешиковуються з однієї колонки в три.

**Шпаргалка по точках перелому Tailwind:**

| Точка перелому | Префікс | CSS-правило | Призначення |
|---|---|---|---|
| За замовчуванням | *(немає)* | `min-width: 0px` | Смартфони (база) |
| Small | `sm:` | `@media (min-width: 640px)` | Великі телефони / малі планшети |
| Medium | `md:` | `@media (min-width: 768px)` | Планшети |
| Large | `lg:` | `@media (min-width: 1024px)` | Ноутбуки |
| Extra Large | `xl:` | `@media (min-width: 1280px)` | Десктопи |
| 2X Large | `2xl:` | `@media (min-width: 1536px)` | Великі монітори |

## 5. Mobile-First та модифікатори на практиці (10 хв)

Покажіть наочну різницю між мисленням через звичайний CSS та мисленням префіксами Tailwind:

1. Напишіть спочатку мобільний варіант блоку:
   ```html
   <div class="text-center p-4 bg-amber-100 md:text-left md:p-8 md:bg-emerald-100">
     <p class="text-sm md:text-base font-medium">Адаптивний текст</p>
   </div>
   ```
2. Відкрийте DevTools у режимі імітації мобільного пристрою:
   - Працюють лише базові класи: текст по центру, фон `amber-100`, малий розмір шрифту.
3. Поступово розширюйте вікно:
   - Як тільки ширина сягне `768px`, вмикаються префікси `md:`: текст вирівнюється ліворуч, колір змінюється на зелений, збільшуються внутрішні відступи.

**Ключова фраза:** *«Префікс `md:` означає не "тільки на планшеті", а "від розміру планшета і на всіх більших екранах". Ви завжди будуєте інтерфейс від малого до великого.»*

## 6. Побудова адаптивного навбара з інтерактивними станами (10 хв)

У Tailwind немає вбудованого JavaScript (як у Bootstrap), тому навбар проектується за допомогою нативного CSS flexbox та простих класів відображення (`hidden` / `block`).

```html
<nav class="bg-slate-900 text-white shadow-lg">
  <div class="max-w-6xl mx-auto px-4 py-3 flex items-center justify-between">
    <!-- Логотип -->
    <a href="#" class="text-xl font-bold tracking-tight text-white hover:text-indigo-400 transition">
      DevBrand
    </a>

    <!-- Кнопка гамбургера для мобільних пристроїв -->
    <button class="md:hidden p-2 rounded-lg text-slate-400 hover:text-white hover:bg-slate-800 focus:outline-none focus:ring-2 focus:ring-indigo-500">
      <svg class="w-6 h-6" fill="none" stroke="currentColor" viewBox="0 0 24 24">
        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M4 6h16M4 12h16M4 18h16"></path>
      </svg>
    </button>

    <!-- Меню десктопу: приховане на телефонах, видиме від md -->
    <div class="hidden md:flex items-center space-x-6">
      <a href="#" class="text-slate-300 hover:text-white transition font-medium">Головна</a>
      <a href="#" class="text-slate-300 hover:text-white transition font-medium">Можливості</a>
      <a href="#" class="text-slate-300 hover:text-white transition font-medium">Ціни</a>
      <a href="#" class="bg-indigo-600 hover:bg-indigo-500 text-white px-4 py-2 rounded-lg font-medium transition shadow hover:shadow-indigo-500/25">
        Увійти
      </a>
    </div>
  </div>
</nav>
```

Поясніть логіку кожної зв'язки:
- `flex items-center justify-between` → вирівнює логотип ліворуч, меню або кнопку гамбургера праворуч.
- `md:hidden` на кнопці → показує іконку гамбургера на мобільних пристроях, але автоматично ховає її на планшетах і десктопах.
- `hidden md:flex` на меню → приховує довгий список посилань на мобільних, але розгортає його у горизонтальний flex-рядок на екранах від `768px`.
- `space-x-6` → утиліта, яка автоматично задає горизонтальний відступ між дочірніми елементами.

## 7. Швидкий огляд: кольори, тіні, заокруглення та псевдокласи (3 хв)

Швидко продемонструйте картку інтерактивного компонента, щоб студенти побачили багатство утиліт дизайну:

```html
<div class="p-6 max-w-sm mx-auto bg-white rounded-2xl shadow-lg hover:shadow-2xl transition duration-300 border border-slate-100 flex flex-col items-start gap-4">
  <span class="bg-indigo-100 text-indigo-700 text-xs font-semibold px-2.5 py-1 rounded-full">
    Новинка
  </span>
  <h4 class="text-xl font-bold text-slate-800">Картка продукту</h4>
  <p class="text-slate-500 text-sm">Tailwind дозволяє плавно комбінувати тіні, радіуси та плавні анімації прямо в класах.</p>
  <button class="w-full bg-slate-900 hover:bg-indigo-600 text-white font-medium py-2 rounded-xl transition duration-200 active:scale-95">
    Купити зараз
  </button>
</div>
```

**Зверніть увагу:**
- `active:scale-95` дає тактильний ефект натискання кнопки без жодного рядка JS.
- `duration-300 transition` автоматично робить усі зміни станів плавними.

## 8. Підсумок + запитання (2 хв)

Резюмуйте ключові знання:
1. **Utility-First** — стилізація через атомарні класи, жодного перемикання між HTML та CSS.
2. **Mobile-First префікси** — базові класи для мобілок, `md:`, `lg:` для адаптації під ширші дисплеї.
3. **Модифікатори станів** — `hover:`, `focus:`, `active:` інтегруються прямо біля кольору чи розміру.
4. **Консистентність** — відступи, розміри і кольори вже стандартизовані фреймворком.

**Домашнє завдання/наступний крок:**
Створити секцію відгуків (Testimonials) з 3 карток за допомогою `grid grid-cols-1 md:grid-cols-3 gap-6`. Картка повинна містити аватар, ім'я, текст та мати ефект підняття при наведенні (`hover:-translate-y-1 hover:shadow-xl transition`).

## Нотатки для викладача

- Для показу коду найкраще використовувати сервіс [play.tailwindcss.com](https://play.tailwindcss.com/) — там наживо працює автодоповнення класів, що допоможе студентам бачити підказки.
- Якщо студенти скаржаться: *«HTML виглядає брудно через таку кількість класів!»*, поясніть, що в реальній розробці (React, Vue, Blade, Astro) верстка розбивається на повторювані компоненти, тож довгий рядок класів пишеться лише один раз.

# Додаток: Словник використаних CSS-класів

Довідник по кожному класу Tailwind CSS, використаному в цьому занятті.

## Розкладка та позиціонування (Layout & Display)

| Клас | Що робить (CSS-еквівалент) |
|---|---|
| `flex` | `display: flex;` |
| `grid` | `display: grid;` |
| `hidden` | `display: none;` |
| `block` | `display: block;` |
| `grid-cols-1` | `grid-template-columns: repeat(1, minmax(0, 1fr));` |
| `md:grid-cols-3` | На екранах від 768px: сітка з 3 рівних колонок. |
| `items-center` | `align-items: center;` (вирівнювання по вертикалі). |
| `justify-between` | `justify-content: space-between;` (елементи по краях). |
| `min-h-screen` | `min-height: 100vh;` (мінімальна висота на весь екран). |

## Відступи та розміри (Spacing & Sizing)

У Tailwind число `1` дорівнює `0.25rem` (4px). Відповідно, `4` = 16px, `6` = 24px тощо.

| Клас | Що робить |
|---|---|
| `p-4`, `p-6` | Внутрішній відступ (padding) з усіх боків (16px, 24px). |
| `px-4` | Внутрішній відступ по горизонталі (ліво + право). |
| `py-2`, `py-3` | Внутрішній відступ по вертикалі (верх + низ). |
| `mb-2` | Margin-bottom: зовнішній відступ знизу (8px). |
| `mx-auto` | Горизонтальне центрування блоку (`margin-left: auto; margin-right: auto;`). |
| `gap-4`, `gap-6` | Проміжок між елементами сітки або флексбокса. |
| `space-x-6` | Горизонтальний відступ між сусідніми дочірніми елементами. |
| `max-w-6xl` | Максимальна ширина контейнера (72rem / 1152px). |
| `w-full` | `width: 100%;` |
| `w-6`, `h-6` | Ширина та висота елемента/іконки (24px на 24px). |

## Кольори та фон (Colors & Backgrounds)

| Клас | Що робить |
|---|---|
| `bg-white` | Білий фон. |
| `bg-slate-100`, `bg-slate-900` | Фон відтінку Slate (світло-сірий або глибокий темний). |
| `bg-indigo-600` | Основний акцентний індиго-колір. |
| `text-white` | Білий колір тексту. |
| `text-slate-800`, `text-slate-600` | Темні та приглушені відтінки сірого для тексту. |
| `text-indigo-600` | Індиго-колір тексту. |

## Типографіка (Typography)

| Клас | Що робить |
|---|---|
| `text-sm`, `text-base`, `text-xl`, `text-3xl` | Розміри шрифту: 14px, 16px, 20px, 30px відповідно. |
| `font-medium`, `font-bold` | Жирність шрифту (вага 500 та 700). |
| `text-center`, `text-left` | Вирівнювання тексту по центру або по лівому краю. |
| `tracking-tight` | Зменшений міжлітерний інтервал (letter-spacing). |

## Рамки, заокруглення та тіні (Borders & Effects)

| Клас | Що робить |
|---|---|
| `rounded-lg`, `rounded-xl`, `rounded-2xl` | Заокруглення кутів (8px, 12px, 16px). |
| `rounded-full` | Повністю округлені краї (форма таблетки або кола). |
| `border` | Додає тонку рамку в 1px. |
| `border-slate-200` | Задає колір рамки. |
| `shadow-md`, `shadow-lg`, `shadow-2xl` | Рівні глибини зовнішньої тіні. |

## Інтерактивні модифікатори та переходи

| Клас | Що робить |
|---|---|
| `hover:bg-indigo-500` | Змінює фон на світліший індиго при наведенні курсора. |
| `hover:text-white` | Робить текст білим при наведенні. |
| `hover:shadow-2xl` | Збільшує тінь при наведенні курсора на картку. |
| `focus:ring-2` | Додає контурне кільце фокусу при навігації з клавіатури. |
| `active:scale-95` | Зменшує розмір кнопки до 95% у момент кліку (ефект натискання). |
