Про курс

Практичний upskilling у Computer Vision

Це практичний upskilling курс для Python-розробників, Data Science, Machine Learning та Software інженерів, які хочуть перейти в напрямок Computer Vision та навчитися будувати системи аналізу зображень і відео.

Ти пройдеш шлях від класичної обробки зображень в OpenCV до нейромережевих рішень CNN, YOLO та inference. Навчишся оптимізувати моделі за допомогою ONNX, OpenCV DNN та MediaPipe, а також працювати з системами трекінгу об’єктів в реальному часі — до повноцінного розгортання готової CV-системи.

Для кого

Python-розробники, Data Science, Machine Learning та Software інженери, які переходять у Computer Vision.

Один проєкт протягом усього курсу

Усі знання ти одразу застосовуватимеш у проєкті, який створюватиметься потягом всього курсу, поступово збираючи та розгортаючи повноцінну CV-систему від першого до останнього заняття.

Що потрібно знати до старту

Для навчання необхідно мати практичні навики програмування на Python і знання бібліотеки NumPy.

Для чого тобі цей курс

Від прототипу до продакшену.

Цей курс допоможе тобі опанувати навички роботи з комп’ютерним зором на рівні CV/ML спеціаліста, який будує системи аналізу зображень і відео від прототипу до продакшену.

Ти опануєш класичні методи обробки зображень та сучасний стек глибокого навчання для CV, навчишся працювати з відеопотоками в реальному часі, оптимізувати продуктивність моделей та розгортати готові CV-рішення як сервіси. У результаті ти станеш конкурентнішим на ринку праці у сфері Computer Vision.

План курсу

18 занять: від пікселя до production

Програма поділена на три блоки. Кожне заняття додає новий шар до твого CV-проєкту.

01

Problem Statement in CV

Конвертація бізнес-вимог у CV-метрики: Precision, Recall, IoU, mAP, FPS, Latency та політика використання даних

02

High-Speed Video Processing

Робота з медіапотоками, буферизація та оптимізація I/O в OpenCV.

03

Image Transformations

Геометричні перетворення, маніпуляція кадрами та нормалізація даних.

04

Color Spaces

Колірні простори, сегментація.

05

Filtering & Morphology

Придушення шуму, бінаризація та морфологічна обробка.

06

Contour Analysis & Geometry

Детекція меж, виділення контурів та точні геометричні вимірювання.

07

Real-time Motion Analytics

Відстеження оптичного потоку (Optical Flow) та віднімання фону.

08

Classical CV Application

Розробка CV-додатку без використання нейромереж.

09

Agentic SDLC in CV

Використовувати AI coding agents для створення та тестування CV pipeline, а AI-assisted annotation — для підготовки й перевірки dataset.

10

CNN & Transfer Learning

Сучасні нейромережеві архітектури, fine-tuning та формат ONNX. Використання PyTorch

11

OpenCV DNN Engine

Швидкий запуск та інтеграція глибоких моделей через OpenCV DNN.

12

Custom YOLO Detection

Навчання, аугментація та виправлення помилок власної YOLO-моделі.

13

Object Tracking & OCR

Трекінг об’єктів (ByteTRACK/SORT), детекція облич, жестів та поз (MediaPipe) та розпізнавання тексту.

14

Model Debugging

Аналіз Edge-cases, помилок моделей.

15

Model Lifecycle & Experiment Tracking

Версіонування моделей, артефактів і експериментів на прикладі MLflow.

16

Deployment & Inference Optimization

Оптимізація інференсу (TensorRT/OpenVINO) для розгортання на ПК або в хмарі (cloud VM). Основні сценарії продакшн-деплойменту та hardware acceleration. Опційно: Edge deployment (Jetson, Raspberry Pi) — за наявності обладнання.

17

Production CV Services

Пакування системи в Docker та розгортання асинхронних API на FastAPI.

18

Production Readiness

Чеклист готовності системи до релізу

  • Робота з AI coding agents та AI-assisted annotation як частина процесу розробки
  • Не потрібне дороге обладнання: інференс на CPU, тренування в безкоштовних хмарних GPU-середовищах

  • Готовий індивідуальний CV-сервіс (Smart Parking, PPE Detection, Traffic Analytics або Quality Inspection), розгорнутий у Docker
  • Практичний досвід з OpenCV, YOLO, PyTorch, ONNX, MediaPipe, FastAPI, OpenVINO та TensorRT
